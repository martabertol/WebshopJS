IT Webshop – HTML, CSS i JavaScript
Pokretanje: raspakirati ZIP i otvoriti index.html u Chromeu. Nije potreban XAMPP.
Odabrati proizvode, količine, dodati u košaricu, po potrebi obrisati stavke, unijeti podatke kupca, državu, grad i način plaćanja te kliknuti Naruči.
Narudžba je simulacija: nema stvarnog plaćanja, slanja ni trajnog spremanja podataka.
Referenca: dohvat_js (1,2,4,6,7,8,9,11,13,16,17.html) i marta/app.js. Primijenjeni DOM, događaji, polja, objekti, petlje, checkbox, radio, select, izračun i dinamički elementi. Logika igre nije prenesena.
